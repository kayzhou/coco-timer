# 词元写作台

本机使用的中文 LaTeX 工作台。界面只有中文，编译使用 XeLaTeX，参考文献样式为 GB/T 7714—2015。服务只监听本机回环地址，不开放注册，也不提供项目共享或多人编辑。

## 启动

需要 Node.js 22、Python 3，以及本机的 `xelatex`、`biber`。中文模板使用 TeX Live 自带的 Fandol 字体和 ctex。

```bash
cd ciyuan
npm start
```

浏览器打开 http://127.0.0.1:4173 。项目文件写在 `ciyuan/data/`，这个目录不进入版本库。换端口可以设置 `PORT`。

## 这一版有什么

- 项目列表、新建、重命名、删除
- 中文模板：中英混排、公式、图片、交叉引用、参考文献
- 文件树、大纲、上传、新建文件
- 自动保存
- 编译、编译日志（原始日志保留，常见错误另有中文说明）、PDF 预览与下载
- ZIP 导入与导出

日志里的 `文件名.tex:行号` 可以点回源码。SyncTeX 双向跳转还不在这一版。

## 测试

```bash
cd ciyuan
npm test
```

没有安装 XeLaTeX 时，编译测试会跳过，其余测试仍会跑。
